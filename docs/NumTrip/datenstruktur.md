# Datenstruktur NumTrip

Die Werte in den Spielfeldern werden als Zahl (int) in einer zweidimensionalen Liste gespeichert. Sprich: jede Zeile ist eine Liste in der Hauptliste. Dies hat nicht nur den Vorteil, dass alle Felder Werte am selben Ort gespeichert werden, sondern zudem sind auch gleich die 'Adressen' der Zahl (also das Feld) der Zahl zugeschrieben.
